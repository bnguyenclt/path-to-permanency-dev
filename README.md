# Path to Permanency Website Redesign

Temporary redesign of nonprofit company Path to Permanency's website, made with Squarespace.

## Description

This was initially a migration of [Path to Permanency](https://www.pathtopermanency.org/)'s website from Wix to Squarespace. Project was ultimately unused, so it was archived and will be listed in my personal portfolio for future reference. Archived website as HTML using [GNU Wget](https://www.gnu.org/software/wget/).

## Getting Started

### Dependencies

* Any modern web browser (Chrome, Firefox, etc.)

### Installing

* Download the repository as a .ZIP file and extract it to access the website's contents.

### Executing program

* Navigate to the `/flute-flugelhorn-43ff.squarespace.com` folder.
* Open `index.html` manually within your preferred file browser or use one of the following commands.
* Google Chrome:
* ```
  google-chrome index.html
  ```
* Firefox:
* ```
  firefox index.html
  ```

## Help

Currently, certain web pages will be missing HTML code and CSS. This is due to these pages originally being dynamically generated by Squarespace, so HTML code could not be archived by Wget.

All content shown here can be found on [Path to Permanency's current website](https://www.pathtopermanency.org/).
